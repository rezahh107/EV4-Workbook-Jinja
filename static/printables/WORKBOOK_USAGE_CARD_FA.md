# برگهٔ استفاده از کتاب‌کار تعاملی Elementor V4

1. فایل `index.html` را مستقیم در مرورگر باز کنید.
2. درس‌ها را به‌ترتیب از منوی کناری دنبال کنید.
3. قبل و بعد هر درس اعتماد خود را ثبت کنید.
4. چک‌لیست‌ها و پرسش‌های توقف را کامل کنید.
5. برای نسخهٔ کاغذی از دکمهٔ «چاپ» استفاده کنید.

این فایل برای استفادهٔ کاملاً آفلاین آماده شده است.
