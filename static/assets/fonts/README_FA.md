# پوشهٔ فونت‌ها

این پوشه برای فونت‌های محلی پروژه نگه داشته شده است.

## وضعیت v15.4

- مسیرهای فونت فارسی `Vazir` و `Vazirmatn` در CSS حفظ شده‌اند؛ اگر فایل‌های فونت را کنار همین README قرار دهید، مرورگر به‌صورت آفلاین از آن‌ها استفاده می‌کند.
- برای واژه‌ها و برچسب‌های انگلیسی، stack اختیاری زیر اضافه شده است:

```css
"Amazon Ember Display", "Amazon Ember", "Inter", "Segoe UI", Arial, sans-serif
```

فایل Amazon Ember Display داخل بسته قرار داده نشده است؛ چون فایل فونت در ورودی وجود نداشت و مجوز بازتوزیع آن برای این بسته احراز نشده است. اگر مجوز معتبر و فایل محلی را خودتان دارید، می‌توانید آن را در این پوشه اضافه کنید و یک `@font-face` محلی تعریف کنید.
