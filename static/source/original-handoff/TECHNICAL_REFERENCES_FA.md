# Technical Reference Pointers

Use official or high-quality sources if web access is available:

- WHATWG HTML Living Standard
- MDN Web Docs: semantic HTML, details/summary, dialog, popover, forms, input, progress, meter, localStorage
- W3C Internationalization: dir and RTL authoring guidance
- Web.dev / MDN for offline and storage guidance

Do not target “HTML6” as a formal standard. Treat modern HTML as HTML Living Standard plus browser-supported Web Platform features.
