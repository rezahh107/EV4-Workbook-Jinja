## کارهایی که فعلاً نکن

- `!important` بی‌دلیل؛
- Z-index بسیار بزرگ؛
- Overflow Hidden برای پنهان‌کردن مشکل؛
- Duplicate Section برای Mobile؛
- Absolute برای متن و Layout اصلی؛
- Class جدید بدون مسئولیت روشن.
