# یادداشت طراحی آموزشی نسخهٔ ۱۳

## اصل راهنما

نسخهٔ ۱۳ ساختار دوره را دوباره بازطراحی نمی‌کند. هدف آن دقیق‌ترکردن چهار چیز است:

1. خودسنجی؛
2. زمان و سنگینی؛
3. حافظهٔ شخصی خطاها؛
4. جمع‌آوری شواهد Pilot.

## زمان پیشنهادی

زمان‌ها بازه‌اند، نه وعده و نه معیار عبور. آن‌ها برای تنظیم انتظار هنرجو استفاده می‌شوند.

```text
proposed time
        ↓ pilot
observed time
        ↓ analysis
revised time
```

## Confidence Check

اعتماد قبل و بعد ثبت می‌شود، اما تنها وقتی معتبر است که هنرجو یک شاهد ارائه کند:

- پاسخ بازیابی؛
- Checkpoint؛
- سؤال انتقال؛
- Debug مستند.

## Error Log

فراشناخت فقط سؤال‌پرسیدن نیست. هنرجو باید الگوی خطاهای خودش را ببیند و اولین بررسی مناسب را به حافظه بسپارد.

## Pilot

نسخهٔ بعدی نباید فقط براساس نقد متنی اصلاح شود. اولویت داده‌های Pilot:

```text
observed learner behavior
> teacher assumption
> proposed timing
```
