# فونت‌ها

برای رعایت محدودیت توزیع فونت، فایل فونت داخل این بسته قرار داده نشده است.

اگر این فایل‌ها را داری، آن‌ها را کنار این README در همین پوشه بگذار:

- `Vazir-Regular.woff2`
- `Vazir-Bold.woff2`
- `AmazonEmberDisplay_Rg.ttf`
- `AmazonEmberDisplay_Md.ttf`

اگر فونت‌ها موجود نباشند، HTML Viewer از fallbackهای سیستم مثل `Vazirmatn`، `Tahoma` و `Segoe UI` استفاده می‌کند.
