# راهنمای نسخهٔ HTML-first

نسخهٔ ۱۴ از HTML به‌عنوان محیط اصلی یادگیری استفاده می‌کند.

## امکانات اضافه‌شده

- کارت معرفی دوره؛
- چک‌لیست تعاملی برای تمرین «چهار گروه را علامت بزن»؛
- پنل آموزشی شبیه Elementor با تب‌های General، Style، Classes و State؛
- مقایسهٔ بصری Flow در برابر Absolute؛
- تبدیل بخشی از کدبلاک‌های فارسی کوتاه به کارت‌های خوانا؛
- حفظ کدهای واقعی به‌صورت LTR و monospace؛
- ذخیرهٔ وضعیت Checkboxها در مرورگر با `localStorage`.

## وضعیت

```text
html_first_components: enabled
interactive_checklists: enabled
local_storage: enabled
real_code_blocks_ltr: true
markdown_archive_preserved: true
runtime_browser_validation: not_performed
```
