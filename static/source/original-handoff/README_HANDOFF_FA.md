# بستهٔ تحویل برای توسعهٔ نسخهٔ بعدی جزوهٔ Elementor V4

این بسته برای ادامه دادن کار در یک چت تازه ساخته شده است.

## شامل چه چیزهایی است؟

- `source/`  
  سورس کامل آخرین نسخهٔ موجود: `v14.1 Premium UX`

- `PROMPT_SENIOR_HTML_DEVELOPER_FA.md`  
  پرامپت کامل برای اینکه مدل بعدی در نقش Senior Offline HTML/Web Platform Developer کار را ادامه دهد.

- `IMPLEMENTATION_BRIEF_FA.md`  
  خلاصهٔ فنی هدف نسخهٔ بعدی.

- `OFFLINE_HTML_WORKBOOK_REQUIREMENTS_FA.md`  
  چک‌لیست الزامات نسخهٔ Offline Interactive Workbook.

## فایل پیشنهادی برای دادن به مدل بعدی

همین ZIP را بده و متن داخل فایل زیر را به‌عنوان prompt اصلی استفاده کن:

`PROMPT_SENIOR_HTML_DEVELOPER_FA.md`

## مبنای فنی

نسخهٔ بعدی باید روی HTML Living Standard و قابلیت‌های آفلاین Web Platform تکیه کند، نه روی HTML6 یا CDN یا فریم‌ورک خارجی.

## هشدار مهم

مفاهیم و روند جزوه نباید حذف شود. کار مدل بعدی تبدیل و ارتقای ساختار و تجربهٔ HTML است، نه خلاصه‌سازی محتوا.
