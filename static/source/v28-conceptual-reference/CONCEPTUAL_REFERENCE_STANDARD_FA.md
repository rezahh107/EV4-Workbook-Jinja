# استاندارد مرجع مفهومی نسخه 28

## هدف
هر درس یک لایهٔ اختیاری، بسته و خودبسنده برای خواننده‌ای دارد که پیش‌نیاز مفهوم را نمی‌داند.

## ساختار ثابت
1. مسئله‌ای که مفهوم حل می‌کند
2. تصویر ذهنی ماندگار
3. تعریف دقیق با زبان ساده
4. رفتار قدم‌به‌قدم
5. معادل Elementor V4
6. تله‌های رایج
7. قوانین طلایی
8. وضعیت اعتبار و منابع

## مرز شواهد
- رفتار UI و محصول فقط از Help Center رسمی Elementor V4.
- قواعد CSS از W3C/CSSWG؛ MDN برای توضیح آموزشی پایه.
- استعاره‌ها derived_explanation هستند.
- فایل کاربر الگوی لحن است و منبع حقیقت نیست.
- ادعاهای مطلق بدون دامنه ممنوع‌اند.
