# اطلس مقدارها و واحدها

این اطلس میان چهار سطح تفاوت می‌گذارد:

1. نوع مقدار در CSS؛
2. واحد عرضه‌شده در کنترل فعلی Elementor V4؛
3. مقدار قابل اعمال با Custom CSS؛
4. مقدار resolveشده در Computed Style.

خانواده‌ها: px، em، rem، درصد، viewport، fr، زمان، زاویه، عدد بدون واحد، keyword، reference و function.
