# راهنمای استفاده از پرامپت اصلی v30

پرامپت اصلی در `MASTER_PROMPT_V30_EN.md` قرار دارد و برای مدل پیاده‌ساز نوشته شده است.

## روش استفاده

1. ZIP پایهٔ v29 را همراه این بسته در اختیار مدل قرار دهید.
2. متن کامل `MASTER_PROMPT_V30_EN.md` را ارسال کنید.
3. تأکید کنید که v29 تنها source base است.
4. از مدل بخواهید پیش از تغییر، تمام فایل‌های planning را بخواند.
5. خروجی باید ZIP کامل نسخهٔ بعدی و Validation Report جداگانه باشد.

## نکته

پرامپت عمداً میان این موارد تفکیک می‌کند:

- حقیقت رسمی Elementor
- قاعدهٔ CSS
- مدل آموزشی مشتق‌شده
- استراتژی پیشنهادی
- موضوع دارای شواهد ناکافی

این تفکیک باید در متن و Registryهای نسخهٔ بعدی نیز حفظ شود.
