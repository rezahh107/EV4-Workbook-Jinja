# بستهٔ تحویل مهندسی نسخهٔ v30

این ZIP یک **بستهٔ برنامه‌ریزی و اجرای نسخهٔ بعدی** است، نه خود Workbook v30.

## منبع پایه

فایل `base/Elementor_V4_Offline_Interactive_Workbook_v29_0_settings_values_units_step_through.zip` تنها مبنای فعال برای ساخت نسخهٔ بعدی است. از هیچ نسخهٔ قدیمی‌تر استفاده نشود.

## هدف نسخهٔ بعدی

تبدیل لایهٔ «واحدها و مقدارها» از آموزش صرف CSS به یک سیستم تصمیم‌گیری مرتبط با معماری Elementor V4، و هم‌زمان عمیق‌ترکردن بخش‌های Variables، Classes، Components، Dynamic Data و Interactions؛ بدون کاهش کیفیت آموزش Layout، Responsive و Step-Throughهای موجود.

## قاعدهٔ حقیقت

- رفتار و مسیر UI در Elementor V4: Help Center و Developer Docs رسمی Elementor.
- قواعد CSS: CSSWG/W3C یا MDN.
- مدل‌های ذهنی و استراتژی‌های Design System: با برچسب `derived_educational_model` یا `proposed_strategy`.
- رفتار نامستند: فقط با fixture یا آزمایش کنترل‌شده؛ در غیر این صورت `insufficient_evidence`.
