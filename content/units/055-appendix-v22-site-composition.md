<h2 class="former-h1">ضمیمهٔ مقدماتی — Theme Builder، Loop Grid و Popup در اکوسیستم Elementor</h2>
<section class="appendix-body">
<p>این جزوه هنوز دورهٔ اصلی خود را روی ذهنیت Layout، Class و Responsive نگه می‌دارد، اما برای اینکه نقشهٔ Elementor ناقص نماند، این سه مسیر سایت‌سازی را باید بشناسی.</p>
<div class="visual-card-grid three">
<div class="visual-card"><strong>Theme Builder</strong><p>برای ساخت Site Partهایی مثل Header، Footer، Single و Archive. این مسیر معمولاً به Elementor Pro مربوط است.</p></div>
<div class="visual-card"><strong>Loop Grid</strong><p>برای نمایش فهرست تکرارشوندهٔ پست‌ها، محصولات یا آیتم‌ها با Template یکدست.</p></div>
<div class="visual-card"><strong>Popup</strong><p>برای طراحی پنجرهٔ پاپ‌آپ و تنظیم شرط نمایش، trigger و rules.</p></div>
</div>
