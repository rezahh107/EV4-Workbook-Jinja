<h2>یادداشت نسخه 28.0 — مرجع مفهومی از پایه و دقیق</h2>
<p>برای هر ۲۸ درس اصلی و تکمیلی، یک مرجع متنی بسته‌شونده افزوده شد. این لایه پیش‌نیازها، تصویر ذهنی، تعریف فنی، رفتار مرحله‌ای، معادل Elementor V4، تله‌ها و منابع را بدون تبدیل متن اصلی به فصل سنگین توضیح می‌دهد.</p>
<ul>
<li>منبع رفتار محصول: Help Center رسمی Elementor V4</li>
<li>منبع قواعد CSS: W3C/CSSWG و MDN برای آموزش پایه</li>
<li>فایل ورودی کاربر فقط الگوی لحن است و به‌عنوان منبع حقیقت استفاده نشده است.</li>
</ul>
