<h2 class="former-h1">واژه‌نامهٔ محافظ Elementor V4</h2>
<section class="appendix-body">
<p>این جدول جلوی مخلوط‌شدن ذهنیت V3، CSS عمومی و زبان Editor V4 را می‌گیرد.</p>
<div class="table-scroll"><table>
<caption>واژه‌های مجاز در این جزوه</caption>
<thead><tr><th scope="col">وقتی می‌گوییم...</th><th scope="col">منظور دقیق</th><th scope="col">عبارت بهتر در تمرین</th></tr></thead>
<tbody>
<tr><td>Div Block</td><td>ظرف سبک برای گروه‌بندی Elementها</td><td>«یک Div Block با نام معنایی Platform Section بساز»</td></tr>
<tr><td>Flexbox Container</td><td>ظرفی با موتور چیدمان یک‌بعدی Flexbox</td><td>برای ردیف/ستون و توزیع فضا</td></tr>
<tr><td>Grid Container</td><td>ظرفی با موتور چیدمان دوبعدی Grid</td><td>برای ردیف و ستون هم‌زمان</td></tr>
<tr><td>ظرف والد</td><td>Parent عمومی، نه لزوماً Element خاص Elementor</td><td>وقتی فقط رابطهٔ Parent/Child مهم است</td></tr>
<tr><td>Element/Widget آماده</td><td>Element/Widget آماده یا Legacy Element/Widget آماده بسته به context</td><td>در V4 اگر منظور Atomic Element است، بگو Element</td></tr>
<tr><td>Section Shell</td><td>نام معنایی لایهٔ بیرونی؛ نه Element قدیمی Section</td><td>Div Block با نقش/نام Section Shell</td></tr>
</tbody>
</table></div>
<p class="golden-rule"><strong>قانون طلایی:</strong> اسم لایه می‌تواند «Section» باشد، اما Element واقعی در V4 را دقیق نام ببر: Div Block، Flexbox Container یا Grid Container.</p>
