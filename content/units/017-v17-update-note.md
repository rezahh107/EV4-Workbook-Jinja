<h2 class="former-h1">یادداشت نسخه 17.0 — تکمیل سرفصل‌های رسمی Elementor 4 و عمق‌بخشی آموزشی</h2>
<section class="appendix-body">
<p><strong>status:</strong> <code class="inline-code" dir="ltr">official_doc_aligned + static_export_observed + pedagogical_deepening</code></p>
<p>این نسخه یک اصلاح واژه‌ای مهم و چند فصل تکمیلی دارد: اصطلاح آموزشی اصطلاح غیررسمی قبلی در متن اصلی با <strong>Global Class</strong> جایگزین شد، چون نام رسمی در Elementor 4 همین است. در عین حال توضیح داده شد که Global Class از نظر رفتاری برای reuse بین چند Element استفاده می‌شود.</p>
<p>فصل‌های تازه برای پوشش شکاف‌های رسمی V4 اضافه شدند: Class Manager، Variables Manager، Components، Atomic Forms، Interactions، Custom CSS، Attributes و Dynamic Tags. بررسی‌های هر فصل به سمت تمرین عملی و شواهد واقعی یادگیری برده شد تا تمرکز دانش‌آموز از فرم‌پرکردن به تصمیم طراحی برگردد.</p>
