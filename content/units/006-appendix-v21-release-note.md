<h2 class="former-h1">یادداشت نسخه 21.0 — مدل ذهنی، عیب‌یابی و آزمایش‌های واقعی رضا</h2>
<section class="appendix-body">
<h2>تغییرهای این نسخه</h2>
<ul>
<li>همهٔ سنجش‌های عددی اعتماد ۱ تا ۵ از درس‌ها حذف شدند و تمرکز به شواهد عملی، چک‌لیست و Debug منتقل شد.</li>
<li>دو بخش «🧪 آزمایش واقعی رضا» اضافه شد: ابهام Flex Row و Duplicate شدن Divها، و مشکل <span dir="ltr">margin-inline-start/end</span> در TUYA.</li>
<li>جدول عیب‌یابی سریع Elementor V4 برای مشکلات رایج Layout، RTL، Position، Global Class و States اضافه شد.</li>
<li>لایهٔ حافظه برای مفاهیم سخت مثل Div/Display/Flex/Grid، Width/Basis/Grow/Shrink، Gap/Margin، Padding/Margin، Normal Flow/Overlay، Z-index/Overflow، کلاس‌ها، RTL و Responsive اضافه شد.</li>
<li>بخش‌های اختیاری «بیشتر بدانید» با <code dir="ltr">details/summary</code> برای توضیح‌های عمیق‌تر اضافه یا بازآرایی شدند.</li>
<li>واژگان فعال جزوه با Elementor V4 هم‌راستا شد: Local Class، Global Class، States، Div Block، Flexbox Container، Grid Container، Display، Flex/Grid.</li>
<li>جدول‌های فعال جزوه caption و scope کامل گرفتند و لینک‌های داخلی ناوبری ترمیم شدند.</li>
</ul>
<p><strong>وضعیت شواهد:</strong> این نسخه یک artifact استاتیک آفلاین است. Runtime واقعی مرورگر و Preview داخل Elementor در این محیط اجرا نشده است.</p>
</section>
