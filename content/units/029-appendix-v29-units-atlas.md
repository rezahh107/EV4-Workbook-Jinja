<h2>📐 اطلس Unit Strategy، تنظیمات، مقدارها و واحدهای Elementor V4</h2>
<p class="status-line"><code dir="ltr">status: verified_reference_with_ui_boundaries</code></p>
<p>این اطلس دو سؤال را جدا می‌کند: <strong>مرورگر چه مقداری می‌پذیرد؟</strong> و <strong>کنترل فعلی Elementor V4 کدام واحدها را واقعاً نشان می‌دهد؟</strong> Help Center رسمی تأکید می‌کند همهٔ Elementها همهٔ واحدها را عرضه نمی‌کنند.</p>
<div class="unit-family-grid">
<section><h3>خط‌کش ثابت</h3><p><code dir="ltr">px</code> طول CSS است. برای Border، Min/Max دقیق یا اندازهٔ محدود مفید است؛ یک CSS px الزاماً یک device pixel نیست.</p></section>
<section><h3>خط‌کش فونت</h3><p><code dir="ltr">rem</code> از root و <code dir="ltr">em</code> از context فونت می‌آید. همان واحد در Width و Font Size مرجع یکسان ولی محل مصرف متفاوت دارد.</p></section>
<section><h3>سهم از مرجع</h3><p><code dir="ltr">%</code> بدون دانستن Property و مرجع ناقص است. Width درصدی معمولاً از containing block می‌آید؛ Font Size درصدی از فونت والد.</p></section>
<section><h3>خط‌کش Viewport</h3><p><code dir="ltr">vw/vh</code> و خانوادهٔ <code dir="ltr">svh/lvh/dvh</code> به viewport وابسته‌اند. Elementor بعضی VW/VHها را عرضه می‌کند؛ واحدهای CSS جدید ممکن است فقط در Custom CSS باشند.</p></section>
<section><h3>سهم فضای آزاد</h3><p><code dir="ltr">fr</code> در Grid سهمی از فضای آزاد است. <code dir="ltr">flex-grow</code> و <code dir="ltr">flex-shrink</code> نیز نسبت‌های بدون واحدند.</p></section>
<section><h3>زمان و زاویه</h3><p><code dir="ltr">ms/s</code> زمان و <code dir="ltr">deg/turn</code> زاویه‌اند. این عددها را نباید مثل طول تفسیر کرد.</p></section>
<section><h3>Keyword و Reference</h3><p><code dir="ltr">auto</code>، <code dir="ltr">stretch</code>، <code dir="ltr">cover</code> و Class/Variable reference واحد طول ندارند؛ آن‌ها دستور یا ارجاع‌اند.</p></section>
<section><h3>توابع محاسباتی</h3><p><code dir="ltr">calc()</code> و <code dir="ltr">clamp()</code> محاسبه می‌کنند، اما فقط ترکیب نوع‌های سازگار معتبر است. پشتیبانی CSS را با عرضه در UI یکی نگیر.</p></section>
</div><section class="lesson-section v30-unit-strategy-intro" id="unit-strategy-v30">
<h3>از «واحد چیست؟» تا «این تصمیم کجا زندگی کند؟»</h3>
<p>Unit Strategy از یک عدد شروع نمی‌شود؛ از <strong>design intent</strong>، Property، نوع مقدار، مرجع محاسبه، مرز UI و دامنهٔ reuse شروع می‌شود. سپس مشخص می‌کنیم مقدار مستقیم بماند، Size Variable شود، داخل Local یا Global Class مصرف شود، و آیا ساختار تکراری واقعاً Component می‌خواهد.</p>
<p class="status-line"><code dir="ltr">derived_educational_model</code> — این مدل تصمیم‌گیری رسمی Elementor نیست؛ از رفتار CSS و قابلیت‌های مستند V4 مشتق شده است.</p>
</section>
