<h2>یادداشت نسخه 30.0 — معماری Design System و Unit Strategy</h2>
<p><strong>status:</strong> <code class="inline-code" dir="ltr">implemented_static_semantic_and_runtime_validation</code></p>
<p>این نسخه لایهٔ «از صفحه‌سازی تا سیستم‌سازی» را به دوره اضافه می‌کند، اطلس v29 را به Unit Strategy ارتقا می‌دهد، دو Step‑Through داده‌محور جدید می‌سازد و آزمایشگاه‌های Variables، Classes، Components، Dynamic Data و Interactions را عمیق‌تر می‌کند.</p>
<ul>
<li>تعداد ۲۱ درس اصلی، ۷ درس تکمیلی و ۶ ایستگاه بدون تغییر حفظ شده است.</li>
<li>نمودار وابستگی Design System از نمودار حل تعارض Style جداست؛ dependency به‌عنوان CSS cascade معرفی نمی‌شود.</li>
<li>تعریف رسمی Variable محدود به Color، Font و Size است؛ tokenها و scaleها با برچسب مدل آموزشی یا راهبرد پیشنهادی آمده‌اند.</li>
<li>همهٔ قابلیت‌های اجرایی همچنان محلی و بدون CDN، analytics، remote font یا dependency شبکه‌ای هستند.</li>
</ul>
