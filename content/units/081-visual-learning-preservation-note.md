<section aria-labelledby="visual-learning-preservation-heading" class="card-surface appendix visual-preservation-note" id="visual-learning-preservation-note"><h2 id="visual-learning-preservation-heading">یادداشت انتقال روح آموزشی TUYA</h2><p>این یادداشت برای انتقال روش آموزشی مرحله‌به‌مرحلهٔ TUYA به جزوه اضافه شده است. اصل مرکزی این است که هر تغییر در Elementor داخل یک Context انجام می‌شود؛ بنابراین قبل از هر مقداردهی باید Element، Class، Breakpoint و محدودهٔ اثر مشخص شود.</p><p>در تمرین‌ها باید وضعیت با برچسب‌های confirmed، provisional و unknown جدا شود. سپس فقط یک اقدام کوچک، با مسیر UI، Element هدف، Class هدف، مقدار و واحد ارائه شود.</p><p>قاعده‌های اصلاحی: Structure اصلی در Flow بماند؛ Absolute فقط داخل Stage کنترل‌شده استفاده شود؛ درصد نسبت به Parent سنجیده شود؛ Min Height برای محتوای پویا امن‌تر از Height ثابت است؛ Rename در Structure با دوبار کلیک روی نام Element انجام شود؛ مقدارهای بصری مثل مختصات Node یا Shadow تا زمان مشاهدهٔ شواهد قطعی محسوب نشوند.</p></section>
